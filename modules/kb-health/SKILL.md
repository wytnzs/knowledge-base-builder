# 知识库体检

> 体检不是打分，是找最堵的那一处，修一个。

## 步骤

1. **跑结构检查**：

```text
python {{SKILL_ROOT}}/scripts/check_kb.py --root "{{ROOT}}" --profile v0
python {{SKILL_ROOT}}/scripts/check_kb.py --root "{{ROOT}}" --stage 9
```

2. **五看**：
   - 入口：积压超过两周没有？有没有第二个入口？
   - 归属：有没有两份一样的？有没有“其他”？
   - 资产：这个月新增几张卡？有几张被用过？
   - 项目：有几个项目说不出下一步？
   - 复盘：最近三次复盘，改过上游文件吗？
3. **只修最堵的一项**，其他记进待办。
4. **留证据**：文件路径、diff、数字、退出码；不接受“我检查过了”。

## 产出

- 一份体检结果：五项各一句
- 一项修复 + 证据

## 验收

- 有实物证据；
- 只修了一项，没有全面翻修；
- 修完再跑一次结构检查，缺项没有增加。

## 失败时

- 五项都堵 → 先修入口，其他下周；
- 修完更乱 → 回滚这一项，记下原因。
