# 方向复盘

> 复盘不是写总结，是改东西。一条都没改，等于没复盘。

## 边界

- 只对一个方向复盘，不一次盘五个；
- 只看这个方向的方向、标准、记录规范、项目、卡片；
- 不改历史记录，只追加。

## 步骤

1. **读三样**：`{{AREAS}}/<方向>/方向.md`、`记录规范.md`、`成长.md`。
2. **问四栏**，让他说，不替他总结：

```text
原来：我原来怎么判断
现在：现在怎么判断
依据：哪件事、哪条证据让我改了
影响：改了哪个文件（卡片/规则/项目/流程）
```

3. **看两样东西**：
   - 标准：这周有没有破底线？（有 → 先修底线，不谈增长）
   - 进展：这周有没有新证据、新项目、新判断？
4. **改一个上游文件**：卡片、方向、记录规范、项目定义、流程，至少改一个。
5. **写进 `成长.md`**：四栏 + 改的文件链接。

## 产出

- `成长.md` 追加一条
- 至少一个上游文件的 diff

## 验收

- diff 里上游文件真的变了，不是只写了一段总结；
- 能说清“下次遇到同样的事，我会怎么做”。

## 失败时

- 想不出改什么 → 说明这周没有新证据，如实记“无变化”，不编；
- 复盘变成流水账 → 只留四栏，删掉过程描述。
