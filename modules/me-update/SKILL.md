# 更新“我”

> `05-Me/` 是 AI 开工前读的说明书，不是简历。改它要慢。

## 边界

- 只改 `{{ME}}/`，不把业务知识、项目记录塞进来；
- **改之前先说清：改什么、为什么**；不静默改；
- 历史判断不改写，只追加或标注。

## 什么时候改

- 身份、立场变了；
- 交付标准变了（写作口吻、审美、配图、脱敏、底线）；
- 长期方向变了；
- 节奏跑了一个月，发现不现实。

## 步骤

1. 说出要改的那一句，和触发它的事；
2. 找到对应文件：`我是谁.md` / `我的偏好与边界.md` / `周节奏.md`；
3. 只改那一段，不顺手重写全页；
4. 检查引用：有没有别的文件依赖这句话；
5. 在 `知识库变更日志.md` 记一句：改了什么、为什么。

## 产出

- `05-Me/` 的一处 diff
- 变更日志一条（影响判断或交付才记）

## 验收

- 改前说明过；
- 只动了该动的那一段；
- 新会话只读 `05-Me/`，AI 能说对新的标准。

## 失败时

- 想大改 → 先改一句，跑一周看效果；
- 不确定是不是标准 → 先放 `00-Inbox`，下次复盘再定。
