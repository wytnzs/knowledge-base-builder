# {{库的名字}}

> 一句话：{{这个库帮谁干成什么}}。

这个库有两种用法：**给人看**（这份 README）和**给 AI 看**（`AGENTS.md`）。
不管用 Claude Code、Codex 还是 WorkBuddy，规则正文都在 `AGENTS.md`；Claude Code 的入口是 `CLAUDE.md`。

## 怎么用

- 有新东西 → 丢进入口，不用管
- 要干活 → 看 `工作回路.md`，按回路走：读 → 做 → 写回
- 要找东西 → 先问一句，再按调用表查
- 每周 → 清一次入口，记一次 `采用记录.md`
- 每月 → 体检一次

## 每个区放什么

| 区 | 放什么 |
|---|---|
| `00-Inbox` | 所有新东西，进来不分 |
| `01-Projects` | 正在做的事，平铺；一个项目一份 `项目.md` |
| `02-Areas` | 长期方向：方向、标准、记录规范、复盘 |
| `03-Knowledge` | 自己的判断、方法、主题；唯一正文 |
| `04-Archive` | 结束的、不用的 |
| `05-Me` | 我是谁、我的标准、偏好、节奏；AI 开工先读 |

## 三条规矩

1. 一个东西只有一个家；
2. 领域管长期，项目管短期，两样分开放；
3. 别人写的和自己的判断分开放；AI 起草，本人拍板。
