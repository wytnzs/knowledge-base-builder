# 工作-数据-技能表

> 一行一件重复工作。指不到 skill 或数据源的，写“待确认”，不编。

| 重复工作 | 触发 | 现有 skill | 数据源 | 产出 | 缺口 | 第一条？ |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

## 怎么选第一条

1. 最近真会发生；
2. 有真实材料；
3. 产出他能直接拿去用；
4. skill/数据至少有一个已经在手。

## 三条判断

- **有 skill 没数据**：工具装了没用，先补数据或换一条；
- **有数据没 skill**：每周在手工搬，先做最小流程；
- **有工作没入口**：先建入口，不急着建整层。
