# 采用计划

> 不按天数。按“这条工作回路跑没跑完”算。
> 能当天跑，就不排到以后。

## 第一次：建库当天，或下一次这件事真发生

- [ ] 准备真实材料，不用编的样例；
- [ ] 读回路卡指定的文件，缺料先补；
- [ ] 产出他能直接用的东西；
- [ ] 写回至少一样；
- [ ] 记 `采用记录.md` 第一行。

## 之后：同一件事每发生一次，就跑一次

- [ ] 不提醒，看他自己会不会来；
- [ ] 来了就按回路走，不重新教；
- [ ] 没来，查断点：触发、入口、缺料、写回太重、回路不真。

## 每跑 3 次，看一次

- 哪一步最费劲：
- 哪一步被跳过：
- 库里的东西有没有被真用上：
- 这次只改哪一处上游（回路卡 / AGENTS.md / 写入规则 / 模块）：

## 什么时候加第二条回路

- 第一条连续跑 3 次、每次不超过 30 分钟；
- 加之前先问：是真的多了一件重复的事，还是想把库做大？

## 如果没跑

- 断在哪：
- 下次什么时候跑：
- 需要先补什么：

> 不写“要坚持”。写清下一次什么时候、做什么。
