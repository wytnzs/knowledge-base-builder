# 触发测试（27 句）

> 用法：把这 27 句分别丢给一个只有本 skill 的会话，看它调不调用。
> 目标：该触发 ≥90%，误触发 0。

## 应该触发（17）

| # | 用户原话 | 说明 |
|---|---|---|
| 1 | 我想建个自己的知识库，但不知道从哪下手 | 最直接 |
| 2 | 我电脑里文件太乱了，想整理成一套能用的系统 | 没提“知识库” |
| 3 | 资料存了一堆，用的时候一个都找不到，怎么弄 | 痛点式 |
| 4 | 帮我搭一个知识库，我是做保险的 | 明确 |
| 5 | 知识库怎么建？有没有什么方法 | 方法式 |
| 6 | 我的知识库建了半年，基本没用起来，怎么救 | 长库模式 |
| 7 | 我想把微信收藏、截图、笔记都归到一起，以后好找 | 入口式 |
| 8 | 给我的工作加一套流程，每周重复的事太多了 | 管线模式 |
| 9 | 我是律师，案子太多，想弄个库管理 | 专业服务型 |
| 10 | 怎么让 AI 记住我的情况，不用每次重新说 | 身份层 |
| 11 | 帮我给知识库打个底，以后换哪个 AI 都能接着用 | 基座 |
| 12 | 我这个库建好了，怎么让别的 Agent 直接上手 | Agent 规则 |
| 13 | 知识库结构要升级，别把我原来的东西弄丢 | 版本 / 升级 |
| 14 | 我想把库拆成主库和数据仓，怎么弄 | 重构 |
| 15 | 我建了知识库，但平时根本想不起来用 | 采用 |
| 16 | 怎么让 AI 直接参与我的日常工作，不只是存资料 | 工作回路 |
| 17 | 我用的不是 Claude Code，是 WorkBuddy，这套能用吗 | Agent 适配 |

| 9 | D 盘满了怎么清理 | 直接做 |
