# 对话样例

> 只示范节奏和动作，不示范话术。用他的材料、他的词。

## 例一：保险代理人，用 WorkBuddy

**第 1 轮**

> 他：我每周要给客户做方案对比，资料散在微信和邮箱里，想建个库。
>
> 你：你现在手上都有什么材料？大概多少、都是些什么？
>
> 他：几十份产品条款 PDF、客户微信记录、以前做过的对比表。
>
> 你：你建这个库，最想让它帮你干成哪件事？
>
> 他：客户问“这两个产品选哪个”，我能半小时给一份对比。
>
> 你：你每周 / 每次重复做的那件事是什么？做完交什么？
>
> 他：每周三给两三个客户做方案对比，交一页纸。

产出 `任务书.md`：为谁、场景、材料、产出、怎么算有用；第一条回路候选“周三客户方案对比”。

**第 2 轮**

> 你：这三份东西——产品条款、客户微信记录、以前做的对比表——你觉得哪些该放一起，哪些分开？
>
> 他：条款和对比表放一起；客户记录分开，不能混。
>
> 你：你平时用哪个 AI 干活？
>
> 他：WorkBuddy，偶尔网页版。

产出 `分区职责表.md`；建出 `00-Inbox`、`01-Projects`、`03-Knowledge`、`04-Archive`、`05-Me`、`客户/`；`.kb-base.json` 记 `agent.primary=workbuddy`、`modules_mode=checklists`。

**第 3 轮**

产出 `写入规则.md`：入口唯一、每周三处理一次、什么建卡、什么不建。

**第 4 轮**

产出 `README.md`、`AGENTS.md`、`AI协作规则.md`、`开场卡.md`、`工作回路.md`、`采用记录.md`、`05-Me/我是谁.md`。

`工作回路.md` 第一条：

```text
回路名：周三客户方案对比
触发：周三上午，客户发来需求
读什么：05-Me/我是谁.md → 客户/<客户>.md → 03-Knowledge/产品对比卡
产出什么：一页纸对比（保障、价格、免责、适合谁）
写回什么：客户档案补一条；新判断进 03-Knowledge/_候选
谁来做：knowledge-card + 人工
算用上：每周 2–3 次，客户拿去做决定
```

**第 5 轮**

> 你：现在用上周那个客户的真实需求跑一遍。先读 `客户/张先生.md` 和两张产品卡。
>
> （读完）你：读到了张先生的预算、已有保单、最在意免责；缺一款产品的免赔额，我先标“待确认”，不编。
>
> （产出）一页纸对比，四项：保障、价格、免责、适合谁。
>
> 你：这一页你直接能发给客户吗？
>
> 他：能，补个免赔额就行。

写回：客户档案补“已出对比、待补免赔额”；候选卡一张“客户最在意免责，不是价格”；`采用记录.md` 记第一行。

> 你：下次同样的事，你第一步做什么？
>
> 他：先看客户档案，再看产品卡。

停。

## 例二：自媒体，用 Claude Code

**第 1 轮** 问材料、目标、重复的事 → 第一条回路“周三发公众号”。

**第 2 轮** 三个区之外加 `素材/`；Agent 选 Claude Code → `.claude/skills`。

**第 3 轮** 入口 + 写入规则。

**第 4 轮** 五个根文件 + `CLAUDE.md` 入口；默认五件套装成 skill。

**第 5 轮** 用上周的真实选题跑：读 `05-Me`、方向、三张 IP 卡、两条评论；产出一版开头和结构；写回一张候选卡“这类开头留人”；记采用记录。

> 你：下次第一步做什么？
>
> 他：先翻评论和 IP 卡，再定角度。

停。

## 两段都遵守的

- 每轮只问一到两个问题，问完就落文件；
- 不问“你的知识体系是什么”，问“上次这件事你怎么干的”；
- 第 5 轮必须用真材料，产出必须能直接用；
- 不替用户判断“这个重要”；
- 跑完就停，不自动装下一组模块。
