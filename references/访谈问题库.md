# 访谈问题库

> 一次只问一到两个。问完就停，等他说。**不要念问卷。**

## 提问的五条规矩

1. **问具体，不问抽象。** 不问“你的知识体系是什么”，问“你上次找一份资料找了多久”。
2. **用他的词。** 他说“案子”就别改成“项目”，他说“素材”就别改成“输入”。
3. **先开放，后选项。** 他卡住了再给两三个选项，选项要具体到能选。
4. **给退路。** “不知道”是合法答案，退路见文末。
5. **问完就做。** 每一轮结束必须落一个文件，不能只聊。

## P0.5 了解你（可选，先问同意）

| # | 问句 | 听什么 |
|---|---|---|
| 1 | 我能看一眼你的工作区和已装的 skill 吗？只看目录和文件头，不读正文 | 同意范围 |
| 2 | 要不要接微信/朋友圈？只读你点名的几段，原文不进库 | 同意 / 拒绝 |
| 3 | 这三件事（拿扫描结果），哪件最近真会发生？ | 第一条回路 |

不同意就跳过，不反复劝。

## P1 定位（五个问题，按顺序）

| # | 问句 | 听什么 | 听到什么算什么 |
|---|---|---|---|
| 1 | 你现在手上都有什么材料？大概多少、都是些什么？ | 数量、形式、来源 | 决定要不要拆来源仓 |
| 2 | 你建这个库，最想让它帮你干成哪件事？ | 一个动作，不是一个愿望 | “提升效率”不算答案，追问到具体事 |
| 3 | 这件事下次什么时候会发生？ | 频率 | 最近不发生，就先不建那一层 |
| 4 | 现在没库，这件事你是怎么干的？ | 现有流程和痛点 | 痛点就是第一版要解决的 |
| 5 | 你每周 / 每次重复做的那件事是什么？做完交什么？ | 重复工作、交付物 | 这是第一条工作回路的候选 |

**如果他说的事在很久以后**（比如“开学”在三个月后）：追问“最近一次同样的事是什么时候”，用最近一次定第一版，不等那一天。

**追问句**（他答得太虚时）：
- “能举个例子吗？上一次是什么时候？”
- “如果这个库只能干成一件事，你选哪件？”
- “干完之后，别人能看到什么？”

## P2 分区（四个问题）

| # | 问句 | 用来判断 |
|---|---|---|
| 1 | 你的材料里，哪些是你自己想出来的，哪些是别人给的、网上存的？ | 判断层 / 来源层 |
| 2 | 哪些东西你会反复用，哪些看完就完了？ | 资产 / 原料 |
| 3 | 最近正在做的三件事是什么？ | 项目层长什么样 |
| 4 | 有没有不能放在一起的东西？比如客户资料、公司文件、家里的事 | 拆库与隐私边界 |

## 跨 Agent（问一次）

> 你平时用哪个 AI 干活？Claude Code、Codex、WorkBuddy，还是直接在网页 / App 里聊？

听三件事：

- 规则文件写哪个：Claude Code → `CLAUDE.md`；Codex / WorkBuddy → `AGENTS.md`；通用 → `AI协作规则.md`；
- 模块怎么装：有 skill 目录就装 skill，没有就装成 `操作模块/` 清单；
- 他能不能让 Agent 读项目文件夹：不能，就多给一张 `开场卡.md`。

## P4.5 工作回路（四个问题）

| # | 问句 | 用来判断 |
|---|---|---|
| 1 | 最近，哪件事一定会发生？ | 触发 |
| 2 | 做这件事时，你第一步会翻什么？ | 读什么 |
| 3 | 做完交出去的是什么？交给谁？ | 产出 |
| 4 | 做完之后，你会记点什么？ | 写回 |

**门**：这四问答得出来，回路卡就能写；答不出来，回 P1 重选那件重复的事。

## 他答不上来怎么办

- **先给例子，不给定义**：“比如有人是拿它管客户，有人是拿它写东西，你更像哪种？”
- **给三个最常见选项**，让他挑一个，再补一句“先按这个跑一周，不对再改”。
- **从材料反推**：让他随手发三份最近的文件，你看了再替他猜，让他确认。
- **允许跳过**：这一层现在定不了，就在进度文件里记“待定”，先走下一层。不要卡死。

## 回答 → 结构的映射

| 听到的 | 结构上的选择 |
|---|---|
| 材料以别人的书、课、文章为主 | 来源仓要重；资产区先小 |
| 材料以客户、案件为主 | 私密仓单独放；主库只放脱敏判断 |
| 输出是文章、视频 | 选题—素材—成品一条线；反馈要回流 |
| 输出是交付物、方案 | 项目制为主；模板和复盘是资产 |
| 一个人干 | 层数越少越好，3–5 个区 |
| 有团队 | 加权限、分工和交接，但第一版仍按一个人建 |
| 存量很大（上千份） | 先建新、不迁旧；旧库冻结只读，用的时候再搬 |
| 完全没存量 | 先建入口和一个项目，别建空目录 |
