# 微信适配

> 微信是「了解你」的可选来源，不是建库的前置条件。
> **先问、同意才做、不同意就跳过。** 不默认扫，不自动装。

## 一、同意书（先念这一屏）

```text
我要读什么：会话列表 / 你点名的几个聊天 / 你自己发的朋友圈
读到什么程度：先只看元数据；正文只读你点名的
存在哪：只在本机；原文进私人来源，不进 03-Knowledge
留多久：用完即删 / 留到项目结束 / 你说了算
怎么退出：随时可以停、可以删、可以只做工作区扫描
风险：第三方读微信数据库可能违反微信服务条款，存在账号风险；
      聊天里有别人的隐私，只提炼，不搬运原文。
```

同意记录写进 `私人来源清单.md`，不靠口头。

## 二、能力矩阵

| 适配器 | 平台 | 聊天 | 朋友圈 | 安装 | 备注 |
|---|---|---|---|---|---|
| `wechat-cli` + Moments 补丁 | Win / Mac / Linux | ✅ | ✅ | 本仓库补丁 + pip | **默认推荐** |
| `wechat-cli` 原版 | Win / Mac / Linux | ✅ | ❌ | `pip install wechat-cli==0.2.6` | 不需要朋友圈时 |
| `wx`（wx-cli） | Win / Mac / Linux | ✅ | ✅ | 源码构建 / 私有仓库 | 功能全，但无公开 release |
| `chatlog-plus` | Windows | ✅ | ✅ | 本地自用（如已装） | 上游已删库，不作为公开默认 |
| `WeChatExporter` | Mac / Windows | ✅ | ❌ | GitHub Releases | 聊天 + 语音/OCR，MIT |
| Wemory | Windows | ✅ | ✅ | 官网安装包 | 闭源，Windows only |
| `wxMoments` / `drriguz` | Win+Mac / macOS | ❌ | ✅ | 源码 | 只导朋友圈，较新 |

**没有单一公开工具同时满足「三平台 + 聊天 + 朋友圈 + 可公开下载」。**
本仓库的 `wechat-cli + Moments 补丁` 是目前最接近的一条路。

### 平台差异（重要）

| 平台 | 聊天 | 朋友圈 | 取钥 | 状态 |
|---|---|---|---|---|
| Windows 10/11 | ✅ | ✅ | 读 `Weixin.exe` 进程内存 | **已实测**（微信 4.1.15.53） |
| macOS Apple Silicon | 待测 | 待测 | 仓库带 `find_all_keys_macos.arm64`；需 sudo / 完全磁盘访问；`task_for_pid` 失败时可能要对微信重签 | 大概率可用，需实测 |
| macOS Intel | 待测 | 待测 | 仓库只有 arm64 取钥二进制，缺 x86_64 | **暂不作为承诺** |
| Linux | 待测 | 待测 | 读 `/proc/<pid>/mem`，需要 root；依赖微信 Linux 客户端 | 未验证 |

**朋友圈解析代码是纯 Python，平台无关；真正的卡点是取钥。**
取不到 `sns.db` 的 key 时，`moments` 会明确报错，不会静默返回空。

## 三、检测

```bash
python scripts/wechat_probe.py
python scripts/wechat_probe.py --format text --show-paths
```

输出：系统、微信数据目录数量、密钥文件、`sns.db` 密钥、已装的适配器、建议用哪个。
只读元数据，不读聊天/朋友圈正文。

## 四、安装（同意之后）

先看方案，不执行：

```bash
python scripts/wechat_install.py --method wechat-cli-moments --dry-run
```

确认后：

```bash
python scripts/wechat_install.py --method wechat-cli-moments --yes
```

它会：

1. 克隆 `huohuoer/wechat-cli` 到固定 commit；
2. 应用 `tools/wechat/patches/wechat-cli-moments.patch`；
3. `pip install -e` 到当前 Python；
4. 不碰密钥、不读数据。

装完，微信保持登录并停在主窗口：

```bash
wechat-cli init
```

如果本机有多个微信账号目录，`init` 会让你选；选错了会在读取时报“没有这个库的密钥”。

## 五、使用

聊天：

```bash
wechat-cli sessions --limit 20
wechat-cli history "张三" --limit 50
wechat-cli search "保险" --limit 50
```

朋友圈：

```bash
wechat-cli moments feed --limit 20
wechat-cli moments feed --user "张三" --limit 20
wechat-cli moments search "保险" --limit 20
wechat-cli moments feed --since 2026-04-01 --until 2026-04-30
```

输出默认 JSON，`--format text` 给人看。

## 六、只提炼，不搬运

从聊天/朋友圈进知识库的，只能是：

- 客户反复问的问题；
- 常见异议和真实卡点；
- 他自己的语气样本、选题、发布节奏；
- 能追到来源的候选判断。

**不进的**：聊天原文、朋友圈原文、证件号、手机号、保单号、病历细节、第三方隐私。
原文留在私人来源；候选卡只写一句话判断 + 依据 + 边界 + 来源指向。

## 七、失败回退

| 现象 | 处理 |
|---|---|
| 没有 `sns.db` 密钥 | 只做聊天，朋友圈跳过 |
| `init` 取不到 key | 确认微信 4.x、已登录、停主窗口；仍失败就跳过 |
| 多个账号目录 | 让本人选；不猜 |
| 微信升级后读不了 | 重跑 `wechat-cli init --force`；仍失败就跳过 |
| 安装失败 | 不阻塞建库，只做工作区扫描和访谈 |

## 八、合规

- 只处理本人有权访问的数据；给别人建库时，必须本人同意；
- 不公开分发第三方的解密二进制；
- 本仓库只放补丁和安装器，不放密钥、不放数据库、不放聊天内容；
- 上游 `chatlog` 已因微信官方函件删库；公开分发前先做合规评估。
