# 第二大脑方法

> 来源：蒂亚戈·福特《打造第二大脑》。
> **只取方法，不搬结构。** PARA 是他的答案，不是每个人的答案。这个技能用它的判断，不用它的目录名。
> 不要跟用户讲 CODE、PARA 这些词；他要的是东西有地方放、找得到、用得上。

## 一、四步循环：抓取 → 组织 → 提炼 → 表达

第二大脑不是为了存，是为了产出。四步走完一圈，产出的东西再回到库里，下一圈更好用——书里叫“知识回收”，跟复利一个道理。

- 抓取：只留让你有反应、真会用上的东西；
- 组织：按“它现在帮哪件事”排，不按学科；
- 提炼：分层，不到用的时候不深挖；
- 表达：拿库里的东西拼出成品，再把新产生的东西收回来。

本技能的 P1–P9 就是这套循环的具体化。

## 二、抓取：什么值得留

书里的四条标准：**有启发性、有实用性、有个性（跟你有关）、有新奇的**。

落到动作上：

- 抓“让你停了一下”的那一段，不抓整篇；
- 不抓“以后可能有用”的，那是数字囤积；
- 抓的时候不分类，先丢入口；
- 只抓你确定会再看的；判断不了就先丢进去，一周后处理时再删。

## 三、组织：以行动为导向（P2 的排序规则）

书里的排序是 PARA：项目 → 领域 → 资源 → 存档。**借它的顺序，不借它的名字。**

P2 判断一份东西放哪，从上往下问，第一个“是”就停：

1. 它现在帮哪个**正在做的事**？
2. 没有的话，它服务哪个**长期方向**？
3. 没有的话，它属于哪类**来源**，留着备查？
4. 都不是，**归档**。

这个顺序就是行动力：越靠前，越会被用到。

- 按用途分，不按主题分；
- 一份东西只归一处；要跨项目，在项目里链接过去；
- 同一条笔记不要既放项目又放来源，会漂移。

## 四、提炼：渐进式，不到用时不深挖

书里的四层，从原始到精华：

1. **土壤**：原文，保留，不改；
2. **原油**：把关键句加粗；
3. **黄金**：在关键句里再挑最关键的高亮；
4. **宝石**：用自己的话写成一句判断，带适用边界。

规则：

- 抓的时候不提炼；用的时候再提炼；
- 每次只做当前需要的那一层，不追求一次到底；
- 最后一定落到“自己的话”，否则还是别人的；
- 三个错误：标太多、没有目标、故作高深。

## 五、表达：用中间产物拼成品

- 不要每次从零写。卡片、案例、模板、复盘，都是“中间产物”；
- 一个成品由若干中间产物拼成；拼过一次，下次还能用；
- 输出完把新产生的东西回收进库：新判断进卡片，新问题进入口，新方法进流程。

## 六、习惯：库靠节奏活

书里三个习惯，直接可用：

- **项目启动清单 / 项目完成清单**：开头定目标，结尾问“当时怎么处理的、目标达成没有、下次改什么”；
- **每周小结 / 每月小结**：每周清入口，每月看方向；
- **处处留意**：用到时顺手改一格，不攒着。

再加一条书里反复强调的：**小步**。先跑通最小一圈，不追求一次建全。

## 七、怎么用这份文件

- 用户问“为什么要这么分”“为什么不能按主题”——用这里的道理回答，用他的话，不用术语；
- 你在两个方案之间拿不准——回到“它现在帮哪件事”这一问；
- 不要主动给用户讲这本书。他要的是库能用，不是学理论。
